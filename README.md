# Mi Proyecto Web

Página en HTML para practicar Git, GitHub y el trabajo con ramas y pull requests.

## Tabla de contenido

- [Instalación](#instalación)
- [Estructura](#estructura)
- [Mejoras implementadas](#mejoras-implementadas)

## Instalación

1. Clona el repositorio con `git clone https://github.com/hateuisa/mi-proyecto-web.git`.
2. Abre `index.html` en el navegador.

## Estructura

- `index.html` contiene la página web.
- `.gitignore` define qué archivos y carpetas debe ignorar Git.
- `README.md` contiene la documentación del proyecto.

## Mejoras implementadas

- Menú con enlaces internos a Inicio, Horario y Contacto.
- Tabla con un ejemplo de horario de clases de lunes a viernes.
- Pie de página con enlaces de texto a Instagram y LinkedIn.
